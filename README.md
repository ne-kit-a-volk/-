# 📸 ФотоХаб — Сервер приема фотографий с БПЛА

**ФотоХаб** — асинхронный сервер, разработанный для приёма, валидации и сохранения изображений, передаваемых с беспилотных летательных аппаратов (БПЛА) во время полета в режиме реального времени. Решение создано с использованием FastAPI и Uvicorn и рассчитано на работу под управлением ОС Linux.

---

## 🚀 Основные возможности

- Прием изображений по HTTP POST-запросу с контрольной суммой (X-Hash)
- Проверка целостности изображения (SHA-256) и его валидности (Pillow)
- Асинхронное сохранение файлов на диск
- Поддержка многопоточной передачи: до 100 запросов/секунда
- Эндпоинты:
  - `POST /upload` — прием изображений
  - `POST /complete` — завершение сессии передачи
  - `GET /status` — статус клиента
- Настраиваемый порт и путь сохранения через аргументы командной строки

## ⚙️ Установка и запуск

### Установка зависимостей

```bash
pip install -r requirements.txt
```

### Запуск сервера

```bash
python server.py --save-path ./saved_photos --port 8000
```

## 🧪 Тестирование

### ✅ Unit-тесты (Pytest)

Файл `tests/test_api.py` содержит:

- Загрузку корректного изображения
- Ошибки при неверной хэш-сумме
- Проверку отклонения невалидного изображения
- Проверку эндпоинтов `/complete` и `/status`

```bash
pytest
```

### 🔥 Нагрузочные тесты (Locust)

Два сценария:

1. **Много клиентов загружают один файл**
2. **Один клиент загружает все изображения из директории**

```bash
locust -f locust_scenario.py --host http://localhost:8000
```
